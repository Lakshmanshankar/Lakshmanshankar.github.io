# Hi, I'm Lakshman

[](https://github.com/Lakshmanshankar#hi-im-lakshman)

Software Engineer with **2.5 years of experience** building analytics platforms, developer tooling, and modern web applications.

Currently an **Software Engineer at Bounteous x Accolite**, working on enterprise analytics infrastructure, semantic data modeling with Cube, PostgreSQL optimization, and permission-aware analytics systems.

Outside of work, I build **PageWrite**, a headless content authoring platform powered by Lexical, MDX, and Astro, and contribute to open source.

To know more about me: checkout [lakshmanshankar.com](https://lakshmanshankar.com/)
