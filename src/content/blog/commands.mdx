## Running Cube

Up

```bash
docker compose up -d # up, down, restart, status
```

Checking Logs

```bash
docker compose logs -f --no-log-prefix cube
```

## Check Mysql Paritions

### Pre-requisites

1. Ensure mysql is installed
2. Ensure that cube container is running

```bash
mysql -h 127.0.0.1 -P 13306
```

2. View the partitions

```sql
SELECT * FROM information_schema.tables;
```

## Pre-aggregations

```bash
curl -X POST \
      http://localhost:4000/cubejs-api/v1/pre-aggregations/jobs \
      -H "Authorization: my-hardcoded-secret" \
      -H "Content-Type: application/json" \
      -d '{
      "action": "post",
      "selector": {
        "contexts": [{ "securityContext": {} }],
        "timezones": ["Europe/London","Asia/Kolkata","Australia/Darwin"],
        "preAggregations": ["orders.orders_by_user"]
      }
    }' | jq | wl-copy
```
